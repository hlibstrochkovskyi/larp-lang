## Executed release gates

[Candidate CI](https://github.com/hlibstrochkovskyi/larp-lang/actions/runs/39248451254)
passed for the exact source commit above:

- Rust formatting, Clippy, 390 workspace tests, and 138 release compiler tests.
- Seventeen release-tool tests and 89 active conformance cases in all four modes:
  source, GC stress, loaded artifacts with GC stress, and formatted artifacts
  with GC stress. No cases were pending.
- Eight reference examples: 40 VM executions and 113 CLI commands.
- Actual plain/JSON CLI identities and genuine historical bytecode v1/v2 execution.
- Two clean Rust 1.99.0 native builds and two package archives with identical bytes.
- Execution of the same archive on both Ubuntu hosts without rebuilding;
  matching source, version, archive/executable digests, and release-document metadata.

The [publication workflow](https://github.com/hlibstrochkovskyi/larp-lang/actions/runs/39251714033)
created the annotated tag at the approved commit, uploaded the three assets to a
draft, downloaded and verified every asset, then published the prerelease and
repeated the downloads and checks. The attached
[`release-evidence.json`](https://github.com/hlibstrochkovskyi/larp-lang/releases/download/v0.1.0-preview.1/release-evidence.json)
retains the candidate reports and additional local preflight results. Its
awaiting-confirmation field records the earlier preparation snapshot; this
publication record and the public Release record the subsequent approved action.

These are finite checks for the declared preview. They do not establish
whole-specification correctness, universal Linux compatibility, signatures,
or a hostile-code sandbox. See the [shipped subset and known limits](https://github.com/hlibstrochkovskyi/larp-lang/releases/tag/v0.1.0-preview.1),
[platform policy](../platforms.md), and [versioning policy](../versioning.md).

## Frozen release and current documentation

The [candidate notes](0.1.0-preview.1.md) and their [descriptor](0.1.0-preview.1.json)
were embedded and hashed before publication. Their preparation-status wording is
historical and intentionally unchanged. The tag, archive, and approved Release
body remain immutable; the repository can receive later documentation or code.

The current `LICENSE` names **Hlib Strochkovskyi** in full. The frozen archive
identifies the same maintainer by the GitHub handle `hlibstrochkovskyi`; its MIT
terms and bytes have not been replaced. README theme improvements and the new
[`pitch-deck.larp`](../../examples/pitch-deck.larp) example are later repository
changes. The example runs on the released CLI but is not a file in that archive.
