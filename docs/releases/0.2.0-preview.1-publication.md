## Executed gates

[Candidate CI](https://github.com/hlibstrochkovskyi/larp-lang/actions/runs/39686149176)
passed for the exact source commit:

- Formatting, Clippy, **480 workspace tests**, and **193 optimized compiler tests**.
- **19 release-tool tests** and **89 active conformance cases in all four modes**.
- Eight reference samples: 40 VM executions and 113 CLI commands; the README
  contract adds five VM executions and 15 commands.
- A multi-file project in five modes: normal/stress source, normal/stress loaded
  artifact, and formatted loaded artifact with stress GC. Original embedded
  paths are unavailable before artifact execution; source snapshots are retained.
- Real plain/JSON CLI identities, emitted wire version, and frozen historical
  v1/v2 artifacts.
- Two clean official Rust 1.99.0 builds and two byte-identical packages.
- The same archive on both Ubuntu hosts, without rebuilding. Both execute the
  legacy corpus and the multi-file project and agree on digests, version,
  preview documents, and project inventory.

The [existing bounded fuzz workflow](https://github.com/hlibstrochkovskyi/larp-lang/actions/runs/39686149181)
also passed. Its unchanged targets do not establish fuzz coverage of every new
source-graph or filesystem-provider API.

The [publication workflow](https://github.com/hlibstrochkovskyi/larp-lang/actions/runs/39687363472)
verified the approved commit, successful candidate run, Actions ZIP digest,
manifest/body hashes, and all asset bytes. It created the annotated tag and a
draft prerelease, uploaded only the approved assets, downloaded and hashed each,
published the prerelease, and repeated the downloads and tag/body checks.
The [attached evidence](https://github.com/hlibstrochkovskyi/larp-lang/releases/download/v0.2.0-preview.1/release-evidence.json)
retains the candidate reports and local preflight summary. The approved binary
archive also passed local extraction, payload, version, corpus, and project checks.

These checks cover this experimental preview and declared hosts. They do not
establish whole-language correctness, a hostile-code sandbox, or universal
platform support. See the [platform policy](../platforms.md) and
[compatibility policy](../versioning.md).

## Frozen release and current repository

The [candidate notes](0.2.0-preview.1.md), [descriptor](0.2.0-preview.1.json),
and README were archived before publication. Their preparation wording records
that earlier snapshot. The tag and released bytes remain immutable; this record
and current README document the completed publication.

The operational `release/preview2-publication` branch contains the publication
workflow and frozen manifests. Its scripts are separate from the tagged language
source and are not merged into `main`. Later source builds must identify their
actual commit even when they share a version string.
